# Home TV releases

Release builds of the Home TV app for Android TV and Fire TV.

**[Download the latest version](https://github.com/praveen2git/home-tv-releases/releases/latest)**

Open the link, then pick the `.apk` file under **Assets**.

## Install on a TV

1. On the TV, install the **Downloader** app from the app store.
2. Allow Downloader to install apps:
   - Fire TV: Settings > My Fire TV > Developer Options > Install unknown apps > Downloader > On.
   - Android TV / Google TV: Settings > Apps > Security & restrictions > Unknown sources > Downloader > On.
3. In Downloader, open:
   `https://github.com/praveen2git/home-tv-releases/releases/latest`
4. Pick the `.apk` file and choose **Install**.

If Developer Options is hidden on a Fire TV, go to Settings > My Fire TV > About and click the device name 7 times.

## First start

- Sign in to Jio, or turn on a playlist in Settings > Channel sources.
- The TV needs internet, and its date and time must be correct. Automatic time is fine.

## Updates

The app checks this page for new versions. When one is out, it offers the update inside the app. You can also install a newer `.apk` over the old one by following the steps above. Your settings are kept.
